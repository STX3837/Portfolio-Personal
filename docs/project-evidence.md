### Alcance de la comparación

Django reserva tras bloquear filas de productos dentro de una transacción atómica; FastAPI condiciona el UPDATE de productos y valida rowcount. Los bloqueos de pedidos existentes, las claves idempotentes de Stripe y las restricciones de unicidad cumplen responsabilidades distintas y no se presentan como mecanismos intercambiables.

En geolocalización no se confirmó la diferencia sugerida entre Haversine Django y consultas PostGIS FastAPI: ambos flujos activos calculan Haversine en Python. Se diferencia el modelo geométrico declarado de las consultas realmente utilizadas.

Pendiente: ejecutar ambas suites y la prueba concurrente Django sobre PostgreSQL; verificar condiciones equivalentes antes de interpretar los artefactos de carga. No se publican fragmentos de código inventados ni resultados experimentales.
